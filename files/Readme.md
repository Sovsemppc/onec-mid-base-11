# Инструкция по начальной настройке конфигурации «1С:Предприятие»

**Назначение:**  
Эта инструкция предназначена для специалистов заказчика. Предприятие уже ведёт учёт в исходной конфигурации. После обновления конфигурации (загрузки новой версии) необходимо выполнить минимальный набор действий, чтобы весь новый функционал (абонентское обслуживание, заявки, Telegram-уведомления, автозаполнение актов, расчёт зарплаты и отчёты) заработал в реальной информационной базе.

Все новые объекты уже добавлены в конфигурацию. Вам нужно только заполнить константы, настроить права и задать параметры для существующих справочников.

## 1. Заполнение констант (обязательно!)

Откройте раздел **Администрирование**, в разделе **Сервис** находятся параметры (константы)

- **Токен управления телеграм-ботом** — токен вашего Telegram-бота.
- **Идентификатор группы**            — числовой ID группы/канала Telegram, куда будут приходить уведомления специалистам.
- **Номенклатура абонентская плата**  — ссылка на элемент справочника **Номенклатура**, который будет использоваться для ежемесячной абонентской платы в актах.
- **Номенклатура работы специалиста** — ссылка на элемент справочника **Номенклатура**, который будет использоваться для работ специалистов.

**Важно:**  
Если нужных элементов номенклатуры ещё нет — создайте их заранее в справочнике **Номенклатура** (вид: Услуга).

## 2. Заполнение графика работы

Для работы функционала **Расчеты** необходимо заполнить график(и) работы.
Откройте раздел **Администрирование**, в разделе **Сервис** находится обработка **Заполнение графиков**.
Установите пероид заполнения, выберите из предопределенных графиков нужный или создайте свой.
Выходные дни указываются через запятую без пробелов - "6,7" или "7".

## 3. Заполнение справочника "Сотрудники"

Для работы функционала **Расчеты** необходимо заполнить справочник "Сотрудники".

Откройте раздел **Добавленные объекты**, справочник находится там.

Для **каждого** сотрудника создайте запись и заполните реквизиты:

- **ФИО**
- **Оклад**
- **Должность**
- **Действует с:** - оклад действует с...
- **ПроцентОтРабот** (только для специалистов)

**Важно:**  
Если у специалиста на дату документа *Обслуживание клиента* нет записи с процентом — документ **не проведётся**.

## 4. Назначение прав доступа (профили групп доступа)

В конфигурацию добавлены готовые поставляемые профили. Назначьте их пользователям.

**Профили и кто их получает:**

| Профиль                  | Кому назначать                  | Что может делать |
|--------------------------|---------------------------------|------------------|
| **Специалист**           | Специалисты                     | Вводить документы *Обслуживание клиента*, видеть отчёт «Выработка специалистов» |
| **Менеджер**             | Менеджеры                       | Планировать заявки, вводить *Обслуживание клиента* |
| **БухгалтерИТФирмы**     | Бухгалтеры                      | Массовое создание актов (*МассовоеСозданиеАктов*), отчёт «Анализ выставленных актов» |
| **КадровикРасчетчик**    | Кадровики-расчётчики            | Начисление зарплаты, график отпусков, отчёты по зарплате и отпускам |

**Как назначить:**
1. Раздел **Администрирование → Настройки пользователей и прав → Пользователи**.
2. Назначьте профили через карточку пользователя.

## 5. Настройка договоров абонентского обслуживания

Все клиенты, у которых есть абонентское обслуживание, должны иметь договор специального вида.

1. Откройте справочник **Договоры контрагентов**(Раздел **Покупки и продажи**).
2. Для каждого такого договора:
   - Установите **Вид договора** = **Абонентское обслуживание**.
   - Заполните новые реквизиты (появятся автоматически на форме):
     - **Дата начала**
     - **Дата окончания**
     - **Абонентская плата**
     - **Стоимость часа**
